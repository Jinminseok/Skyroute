이 데모는 어떻게 동작하나요?

  • 실제 SkyRoute Spring Boot 애플리케이션을 테스트 데이터로 실행한 뒤, 역할별 화면과 API 응답을 그대로 저장해 만든 사이트입니다.
  • 서버와 DB 없이 GitHub Pages에서 동작하며, 링크 · 검색 · 예매 단계 이동 · 화면 안의 조회 요청은 저장된 응답으로 재현됩니다.
  • 등록 · 수정 · 삭제 · 결제는 실제로 반영되지 않고 안내 메시지만 표시돼요.
  • 데이터 기준일은 2026년 10월 25일입니다. 저장되지 않은 조건으로 검색하면 가장 가까운 조건의 결과를 보여줍니다.
